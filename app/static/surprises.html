How the model's pre-transfer prediction stacks up against the real outcome.

For every scored permanent transfer, a version of the model that never saw that transfer's own outcome (5-fold cross-validated, using only pre-transfer data) made its best guess. This page ranks transfers by the gap between that guess and what actually happened: overachievers the model didn't see coming, busts it didn't see coming either, and, via the Show filter below, the calls it got closest to right. Not every transfer has a prediction here: the same handful missing a required feature (fee, height, origin league) are excluded from the model's training too.
